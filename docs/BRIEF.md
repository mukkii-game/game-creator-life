# 企画の依頼書(会議室から、2026-10-15)

Mukkii の注文をそのまま整理したもの。SPEC.md と PLAN.md はこれを元に作る。

## 作品
- 仮題: **『1200万人のゲームクリエイター人生』**
  - 数は「今のゲーム開発者の総数見込み」。SlashData の推計は 2024 年初めに 1110 万人(趣味・学生を含む)。https://www.slashdata.co/post/there-are-11-1-million-game-developers-in-the-world
  - 2026 年の見込みとして 1200 万人を仮置き。仕事にしている人だけで数えるなら桁が変わる。どちらで行くかは PLAN で決めて理由を書く。
- 着想元: Jin Hwi-eus 氏の『80億分の1』(2026-10-05 公開のブラウザゲーム)。
  - 141 か国の統計で、生まれる国や家庭がガチャで決まる。
  - 「健康・幸福・知識・人間関係」の数値と、進学・仕事・恋愛などの選択がある。
  - 同じ 1 秒に生まれた 4 人が並んで進む。
  - 時代を選べる。速度を変えられる。「おまかせ」がある。
  - 出典: https://automaton-media.com/articles/newsjp/20261013-473180/ 、https://news.denfaminicogamer.jp/news/2610142g
- 反面教師: 日本特化版『1.2億分の1』(AUTOMATON 2026-10-15)。https://automaton-media.com/articles/newsjp/20261015-473497/
  - Mukkii の見立てでは、ただの縮小再生産の丸写しで叩かれている。

## 方向(Mukkii が決めたこと)
- **模倣だが、笑えるパロディに振り切る。** 感動作ではなく「あるあるギャグ」として許されるもの。
  - 模倣そのものをネタにしない。今回の題材に合うレイアウト・絵柄・イベント・シナリオにする。
  - 絵柄は似せない。
  - **新しいシナリオ展開かシステムを必ず入れる**(ひねり)。
- **人生の範囲は、ゲームクリエイターとしての始まりから終わりまで。**
  - 始まり: 早くて 18 歳、普通は 22 歳、遅く始める人もいる。
  - 終わり: 普通は定年の 60 歳。バイトのようなゲームの仕事で 65 歳・70 歳まで続ける人もいる。
  - 本当に死ぬ必要はない。「ゲーム開発者としての死」が来たら終わり。
  - ずっと現役が普通。ただしクビや心が折れて他の仕事に行く、何かの理由で別の職種になる、もある。
- **時代**: テレビゲームが初めて世に出たころ(ファミコンより少し前)から、今より少し先の未来まで。
  - 時期は史実に合わせる。史実はできるだけ集めて、面白おかしくする。
  - 今のあたりから、AI の影響をイベントに入れ始める。
- **狙い**: すごく笑える、イベントが次々続く。ときどきある選択は、本当に悩ましいものにする。
- **作る期間: 1〜2 日。**

## 進め方(Mukkii が決めたこと)
- 最初に最上位のモデル(Fable)が、全体像と進め方を高い精度でまとめる。そのあとは Opus か Sonnet が続ける。
  - 司令塔のセッションと、パート担当のセッションに分けて並列で進めてもよい。
- Mukkii は「最強の思考力を持つ ASTRA(OpenAI の GPT-6 Astra)」にも最初の計画を立てさせたい。
  - Astra は Plus では Codex と ChatGPT Work でだけ使える。
  - 会議室の「独立セカンドオピニオン」の手順で行う。Astra には Fable の結論を見せず、同じ依頼だけを渡す。それぞれの案を出し、最後に並べて良いところを合わせる。
- この作品は、会議室にまとめた知見がうまく使えるかの**試金石**でもある。使った資料と、効いた・無かったを HANDOFF の「全体に共有したい気づき」に `会議室: <ファイル> / 役立った・古かった・無かった` で必ず残す。

## 雛形の決まりで特に関係するもの
- 1 つの repo に push する者は 1 つ。並列のパート担当はそれぞれ作業ブランチで作り、司令塔が main にマージする。
- 乱数は core/rng(人生ガチャを seed で再現できるように)。数値は tuning.ts。「おまかせ」は bots.ts と同じ入口で。
- `?lang=en`・操作 3 種・アプリ内ブラウザの案内(core/inapp.ts)は雛形どおり。SNS で広がる作品なので、結果の画面をシェアしやすくする。
- 公開は Cloudflare(main に push で自動)。
