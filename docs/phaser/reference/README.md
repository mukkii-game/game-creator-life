## なぜ .claude/skills から出したか

29 本を全部スキルとして置くと、その説明文(合計 約7,800文字)が毎回コンテキストに載り、
しかも内容が互いに重なるため、AI がどれを読むべきか判断しにくくなる。
題目を探してから 1 枚だけ開く形にすれば、かかる費用は「一覧を見る」分だけで済む。
