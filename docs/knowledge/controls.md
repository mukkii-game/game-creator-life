# 操作の既定(キーボード&マウス・スマホ・コントローラ)

**どの作品も 3 つ全部で遊べるようにする。** 実装は `src/core/input.ts`。作品で変える時は、この表を SPEC.md に写して直す(タイトル画面か一時停止に操作説明を出す)。

## 移動の方式は 2 つ(作品が選ぶ)
| 方式 | キーボード | コントローラ | マウス | スマホ |
|---|---|---|---|---|
| **スティック型**(既定) | 矢印 / WASD | 十字キー / 左スティック | (使わない。クリックは決定) | **バーチャルパッド**。`floating` = 画面の左半分のどこを触ってもそこが中心 / `fixed` = 決まった場所(既定 左下)に常に出す |
| **直接型**(`direct`) | 矢印 / WASD(触ったらこちらが優先) | 十字キー / 左スティック | **ポインタの位置へそのまま動く** | **ドラッグした指の位置へそのまま動く** |

どれにするかは `new UnifiedInput(scene, { touch: 'floating' | 'fixed' | 'direct' })`。雛形では F2 のつまみ「スマホの移動」(`input.touch`)で遊びながら切り替えられる。
状態は `axisX`・`axisY`(-1〜1。キー・十字は ±1、スティックとパッドは傾き)と、直接型の時の `target`(目指す画面座標)。

## ボタン
| 意味 | キーボード | マウス | スマホ | コントローラ(標準配置) |
|---|---|---|---|---|
| 決定・アクション | Space / Enter / Z / X | クリック(直接型は右クリック) | 画面の右半分をタップ(直接型は 2 本目の指) | A / B |
| 一時停止 | Esc / P | (作品で ⏸ ボタンを置く) | (作品で ⏸ ボタンを置く) | START |
| 調整パネル | F2 | — | 画面左上を 3 回タップ | — |

## 決まり
- 「押した」は押した瞬間だけ(押しっぱなしで連射にしない。連射が要る作品は、連射の間隔をつまみにして足す)。
- 入力を `window` だけで受けない(`AGENTS.md`「知らないと必ず溶かす」)。音はどの入力の最初の 1 回でも鳴らせるようにする(`core/audio` の unlock)。
- 作品ごとに変えてよい(例: 照準が要るならマウス位置・右スティック・タッチ位置)。ただし 3 つのどれかで遊べない状態にはしない。
- 確かめ方: キーボードだけ / タッチだけ(`?debug=1` で生イベントを見る)/ コントローラだけ、でタイトルから 1 回遊べるか。3 方式のタッチの動きは Playwright のタッチ操作で確かめられる(2026-10-13、3 方式とも移動を確認)。
